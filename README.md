# Курсовий проєкт: Розробка ігрового застосунку «ARKANOID: HELLBREAK EDITION» на базі бібліотеки Pygame

##  Опис проєкту
Цей проєкт є сучасною модифікацією класичної аркадної гри **Arkanoid**, реалізованою мовою програмування **Python** з використанням бібліотеки **Pygame**. Особливістю архітектури є фокус на динамічному ігровому процесі (Game Feel), інтеграції візуальних ефектів (Screen Shake, Particle System, Flash) та повній синхронізації дій з аудіосистемою застосунку.

---

##  Технічний стек
* **Мова програмування:** Python 3.x
* **Основний фреймворк:** Pygame (робота з графікою, обробка подій, ігровий цикл)
* **Допоміжні модулі:**
  * `pygame.mixer` — керування аудіопотоками (музика та звукові ефекти).
  * `json` — серіалізація та десеріалізація даних для збереження рекордів.
  * `math` — математичне моделювання анімації заднього фону.
  * `random` — генерація рівнів, бонусів та поведінки часток.
  * `os` — перевірка наявності системних файлів та ресурсів.

---

##  Архітектура та структура коду

Проєкт побудовано за принципами **об'єктно-орієнтованого програмування (ООП)**. Код розділено на логічні класи та модулі:

### 1. Основні класи об'єктів (Game Entities)
* `Ball` — інкапсулює логіку руху м'яча, перевірку виходу за межі екрана (ліва, права та верхня стіни) та інверсію векторів швидкості.
* `Paddle` — керує платформою гравця. Реалізує комбіноване керування: дискретне (клавіші `A`/`D`, стрілки) та аналогове (плавне слідування за курсором миші з коефіцієнтом згладжування `0.15`).
* `Bonus` — відповідає за випадіння та логіку трьох типів модифікаторів:
  * `expand` (збільшення платформи);
  * `score` (нарахування додаткових очок);
  * `multiball` (генерація додаткових м'ячів).
* `Particle` — система часток, що генерується в точці руйнування блока для створення візуального ефекту «вибуху».
* `Button` — універсальний клас інтерфейсу для обробки подій миші (`hover`, `click`) та рендерингу UI.

### 2. Ігровий цикл (Game Loop) та Менеджмент станів
Керування грою реалізовано через кінцевий автомат у головному циклі `while running` за допомогою булевих прапорців (`menu`, `paused`, `game_over`, `victory`). Частота оновлення зафіксована на рівні **60 FPS** за допомогою `pygame.time.Clock()`.

##  Ключові рішення та фічі

###  Обробка колізій (Collision Detection)
Зіткнення м'яча з об'єктами реалізовано через перевірку перетину прямокутних областей (`pygame.Rect.colliderect`). 
* **Механіка відскоку від платформи:** Кут відскоку залежить від точки удару. Обчислюється зміщення (offset) відносно центру платформи, що дозволяє гравцеві свідомо направляти м'яч у потрібну сторону.

###  Візуальні ефекти (Juiciness & Feedback)
* **Screen Shake:** При колізіях із блоками чи платформою активується зміщення матриці екрана на випадкові координати (ефект тряски), що згасає з кожним кадром.
* **Ball Trail:** Масив з останніх 20 координат м'яча використовується для малювання градієнтного шлейфу, що додає динаміки.
* **Procedural Background:** Текстура заднього фону генерується процедурно за допомогою синусоїди `math.sin` та системного часу, створюючи ефект пульсації «пекельного» фону.

###  Аудіосистема та збереження даних
* Реалізовано асинхронне відтворення фонової музики (`pygame.mixer.music`) у циклі та точковий виклик звукових ефектів (`pygame.mixer.Sound`) без затримок основного потоку.
* Найкращий результат (High Score) автоматично записується у файл `highscore.json` при програші або перемозі та зчитується під час запуску гри.

##  Керування
* **Рух платформи:** Клавіші `A` / `D`, стрілки `Вліво` / `Вправо` або рух миші.
* **Пауза:** Клавіша `ESC`.
* **Перезапуск гри:** Клавіша `R` (на екранах Game Over / Win).
